# Supercart Store (Android WebView app)

Wraps https://supercart-iota.vercel.app/store/login in an Android app.
Location permission: the site's request shows the standard Android Allow / Don't allow dialog.

## APK banane ke tareeke
1. Naya GitHub repo banao aur is folder ke ANDAR ki saari files upload karo (bahar wala folder nahi).
2. Agar `.github` folder na gaya ho to `.github/workflows/build-apk.yml` Add file -> Create new file se banao.
3. Actions -> Build APK -> Run workflow. Artifact `supercart-store-apk` me app-debug.apk milegi.

Icon: `icon-512.png` se build ke time par apne aap banta hai.
